# Marlana Pellegrino — Portfolio

A single-page portfolio site: `Work · LinkedIn · Contact · Resume`.

## Before publishing on GitHub Pages

1. **Resume**: drop her real resume PDF into this folder and name it exactly `resume.pdf` (the nav link already points to it).
2. **Email**: `index.html` currently uses a placeholder email address (`hello@marlanapellegrino.com`) in two spots — the "Email Me" button and the footer. Search for `mailto:` and replace both with her real address.
3. **LinkedIn URL**: already set to `https://www.linkedin.com/in/marlanapellegrino/` in the nav, hero, and contact section.
4. **Case studies**: the three Work cards (Edward Jones, Wells Fargo Merchant Services, Lowe's) are placeholders marked "Case study coming soon." Swap in full write-ups, or link each card to its own page, whenever that content is ready.
5. **Optional**: add a headshot or a subtle background image if you want one — none is included, to keep the file lightweight and the layout distinct from other portfolios.

## Publishing to GitHub Pages

1. Create a new GitHub repo (e.g. `marlana-pellegrino.github.io` for a root domain, or any name for a project site).
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf` to the repo root.
3. In the repo's Settings → Pages, set the source to the `main` branch, root folder.
4. GitHub will publish it at `https://<username>.github.io/` (or `/<repo-name>/` for a project site).

resume.pdf    — add this yourself (see step 1 above)
