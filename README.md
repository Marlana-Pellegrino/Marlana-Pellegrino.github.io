# Marlana Pellegrino: Portfolio

A two-page portfolio site: `index.html` (Work, About, Selected Work) and `contact.html` (Contact Details). Nav links: Work, LinkedIn, Contact, Resume.

## Before publishing on GitHub Pages

1. **Resume**: drop her real resume PDF into this folder and name it exactly `resume.pdf` (the nav link and the Contact page both point to it).
2. **Email and phone**: already set to her real email (`marlanapellegrino76@gmail.com`) and phone number in the footer and on the Contact page.
3. **LinkedIn URL**: already set to `https://www.linkedin.com/in/marlanapellegrino/` throughout.
4. **Case studies**: the three Work cards (Edward Jones, Wells Fargo Merchant Services, Lowe's) are placeholders marked "Case study coming soon." Swap in full write-ups, or link each card to its own page, whenever that content is ready.
5. **Optional**: add a headshot or a subtle background image if you want one. None is included, to keep the file lightweight.

## Publishing to GitHub Pages

1. Create a GitHub repo named exactly `<username>.github.io` for a personal root domain.
2. Upload `index.html`, `contact.html`, `styles.css`, `script.js`, and `resume.pdf` to the repo root.
3. Confirm the default branch is `main`. For a `<username>.github.io` repo, GitHub Pages publishes automatically from it.
4. The site will be live at `https://<username>.github.io`.
